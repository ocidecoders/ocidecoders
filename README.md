Ocide Coders is a small web studio based in Chattogram, Bangladesh — working with clients worldwide. We build hand-coded websites from $1, create internal tools, and quietly ship digital products.

We are **a part of Ocide**.

**What we do:**
- Hand-coded websites (HTML, CSS, JavaScript)
- Custom web applications
- SEO setup and optimization
- UI/UX design

- You own the code — no subscriptions, no lock-in
- Pricing from $1 (landing pages) to $20+ (web apps)
